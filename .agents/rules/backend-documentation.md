# Backend Documentation Rules

## Backend Documentation Requirements
- For each storage backend provider, you MUST write detailed JSDoc comments for all public classes, methods, parameters, and return values to guide the end user on how to use it correctly.
- You MUST write a detailed "how-to" setup guide in the `docs/` directory. The guide must contain step-by-step instructions on setting up credentials on the provider (e.g. developer portal setup, OAuth redirect URLs, scopes needed).
